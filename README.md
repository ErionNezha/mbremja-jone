# 🔞 Mbrëmja Jonë

**Loja romantike për çifte — vetëm për 18+**

🎮 **[Luaje live këtu](https://mbremja-jone.netlify.app)**

</div>

## 💋 Çfarë është?

"Mbrëmja Jonë" është një lojë dixhitale **"e vërtetë apo sfidë"** për çifte, tërësisht në shqip.
Dy lojtarë tërheqin karta me radhë — pyetje romantike, sfida flirtuese dhe
prova intime që eskalohen nivel pas niveli.

## 🃏 64 karta në 4 nivele

| Niveli | Emri | Përmbajtja |
|--------|------|------------|
| 💋 1 | **Shkëndija** | Flirt i ëmbël dhe romantik (16 karta) |
| 🔥 2 | **Tensioni** | Pyetje e sfida të guximshme (16 karta) |
| 🌙 3 | **Pas Mesnate** | Intime, pa kufij, pa turp (16 karta) |
| ⛔ 4 | **EROZONE** | Zona e ndaluar — këtu **s'ka ikje**, çdo kartë DUHET kryer (16 karta) |

Llojet e kartave: 💬 *E vërtetë* · 🔥 *Sfidë* · 💞 *Për të dy*

## ✨ Veçoritë

- 🔞 **Age gate 18+** në hyrje + **PIN 4-shifror** që e mban lojën private
- 🃏 Animacion flip 3D i kartës + dritë (glow) me ngjyrën e nivelit
- ✨ Xixëllonja fluturuese, shkëlqim gold i animuar, shpërthim shkëndijash
- 🏆 Pikë për çdo kartë të kryer · 😏 dënimi: *kush e kalon kartën i detyrohet tjetrit një dëshirë*
- 📊 Shirit progresi i animuar · 🔀 ripërzierje kuverte
- 📱 Mobile-first, punon offline (single file, pa backend)

## 🛠️ Teknologjia

Një file i vetëm `index.html` — HTML + CSS + JavaScript vanilla, zero dependencies.
Të dhënat (PIN, emra) ruhen vetëm lokalisht në browser (`localStorage`).

```
git clone https://github.com/ErionNezha/mbremja-jone.git
# hape index.html në browser — kaq!
```

## 📜 Rregullat

1. Tërhiq kartën kur të vijë radha jote.
2. Kryeje **ose** kaloje (përveç në EROZONE — aty s'ka ikje 😈).
3. Kush e kalon, i detyrohet tjetrit një dëshirë.
4. Argëtohuni. 🌙
